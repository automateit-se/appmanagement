# App Management 0.1.3

## Changes

- Setting up and managing edge clients on a server can be limited to users whose IoT Open role has a particular permission. Give a dedicated role in IoT Open a permission of its own and set it as `EDGE_PERMISSION` in `.env`. Other users still see the edge client's status and log if their role allows it, but cannot set one up or change it, and the page tells them that a role with a particular permission is needed. As before, IoT Open's roles decide: the permission is read from the user's role, also when signing in with an API key.
- `EDGE_PERMISSION` and `EDGE_ADMINS` can be combined; both then apply.

## Upgrade

Download `deploy/compose.yml` again (it passes `EDGE_PERMISSION` on), set `APPMANAGEMENT_TAG=0.1.3` and optionally `EDGE_PERMISSION` in `.env`, then `sudo docker compose pull && sudo docker compose up -d`.
