# App Management 0.1.12

## Fixed

- **Installing an app in a new organization no longer fails with *Internal Server Error* because of a long description.** App Management sent the app's whole README as its description when it created the app in IoT Open. IoT Open answers HTTP 500 when the description is too long (about 6 kB went through, 10 kB did not), for example for *Lokal dashboard* 0.1.3. The description IoT Open gets is now at most 4,000 characters, cut at a paragraph and ending with a link to the whole text on GitHub. If IoT Open still answers 500 when the app is created, App Management tries once more with only the short description.
- The same limit applies when an app's description is updated from GitHub, which could fail silently before.

## Changed

- **An installation that fails says where.** The error names the step and IoT Open's call, for example *Skapar appen i IoT Open: Internal Server Error (HTTP 500 på POST /api/v2/edge/app)*, instead of only *Internal Server Error*.

## Upgrade

`sudo appmanagement-update`, or by hand `APPMANAGEMENT_TAG=0.1.12` in `/opt/appmanagement/.env`, then `sudo docker compose pull && sudo docker compose up -d`.
