# App Management 0.1.5

## Changes

- **Messages on MQTT.** A new *MQTT* tab on an installation shows what its apps publish on `obj/…` and `evt/…`, wherever the installation's edge client runs. It lists the topics that have had messages lately, lets the user pick topics or write patterns with `+` and `#`, and shows the messages: earlier ones from IoT Open's history (up to 7 days) and new ones live. Everything is read with the signed-in user's own token.
- **An app's MQTT log.** The picked topics can be kept as an app's log (in the browser), and the app's card then gets *MQTT log*.
- README: a convention for apps that log to MQTT (`obj/<app>/<instance id>/log` with `msg`).

## Upgrade

Set `APPMANAGEMENT_TAG=0.1.5` in `.env`, then `sudo docker compose pull && sudo docker compose up -d`. If the edge proxy in front buffers responses, live messages need `X-Accel-Buffering` to be honoured (nginx does this by default).
