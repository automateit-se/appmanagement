# App Management 0.1.7

## New

- **Edge status on the list of installations.** Every installation that has an edge client gets a green *Online* or red *Offline* on its card, wherever the edge client runs (here, on a gateway or a Raspberry Pi). Installations without an edge client show nothing. The status is read for all installations at once, with the signed-in user's own token, and refreshed every minute.

## Upgrade

Set `APPMANAGEMENT_TAG=0.1.7` in `.env`, then `sudo docker compose pull && sudo docker compose up -d`.
