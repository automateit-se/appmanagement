# App Management 0.1.8

## Changed

- **Password fields in app settings.** A setting of type `password` in an app's `app.json`, for example a PIN or an API key, is hidden while it is typed and is never filled in by the browser's saved passwords. Used by the edge app [Lokal dashboard](https://github.com/automateit-se/edge-app-local-dashboard) for its PIN/password and its optional API key.

## Upgrade

Set `APPMANAGEMENT_TAG=0.1.8` in `.env`, then `sudo docker compose pull && sudo docker compose up -d`.
