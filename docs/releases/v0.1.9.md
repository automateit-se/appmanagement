# App Management 0.1.9

## New

- **Published ports for Docker edge clients.** An app in an edge client that has its own web page, such as the edge app [Lokal dashboard](https://github.com/automateit-se/edge-app-local-dashboard) on port 8090, can now be reached from the network.
  - With `EDGE_PORT_RANGE` set, for example `18000-18099`, the edge client's page has a panel *Publicerade portar*. It lists the published ports with a link, and *Ändra portar* sets which app port is published on which server port. The next free port is suggested, and each edge client can have at most five.
  - Changing the ports restarts the edge client briefly, because Docker can only set ports when a container is created. The ports are kept when the edge client is updated.
  - A server port can only be used by one edge client. If a port turns out to be taken by something else on the server, the edge client starts again with the ports it had, and the page says which port was taken.
  - Publishing follows the same rules as setting up an edge client on the server (`EDGE_PERMISSION`, `EDGE_ADMINS`).
  - `EDGE_PORT_BIND` (default `0.0.0.0`) sets which address the ports listen on. The apps answer on plain http, so publish only on a network you trust.

## Changed

- **The apps' data is kept when an edge client is recreated.** Each edge client gets a second volume, `iotopen-edge-<installation>-data`, for `/var/lib/iot-open`, so the local dashboard's cache and history survive an update or a port change. Existing edge clients get the volume at their next update. *Ta bort* with *Ta även bort sparade credentials och appdata* removes both volumes.

## Upgrade

Set `APPMANAGEMENT_TAG=0.1.9` in `.env`. To publish ports, also add for example `EDGE_PORT_RANGE=18000-18099`, and get the new `compose.yml`, which passes the setting on:

```
cd /opt/appmanagement
sudo curl -fsSLO https://raw.githubusercontent.com/automateit-se/appmanagement/main/deploy/compose.yml
sudo docker compose pull && sudo docker compose up -d
```

Open the range in the server's firewall only towards the local network.
