# App Management 0.1.2

## Changes

- `EDGE_ADMINS` accepts e-mail domains. `EDGE_ADMINS=@example.com` lets only IoT Open users whose e-mail address ends in `@example.com` set up and manage edge clients on this server. It also works when signing in with an API key, since the key belongs to an IoT Open user. Entries can be mixed: e-mail addresses, user ids and domains, comma-separated.
- Users who are stopped by `EDGE_ADMINS` still see the edge client's status and log if their IoT Open role allows it, and the page explains that only selected users may set up and change edge clients on this server.

## Upgrade

Set `APPMANAGEMENT_TAG=0.1.2` in `.env`, optionally `EDGE_ADMINS=@example.com`, then `sudo docker compose pull && sudo docker compose up -d`.
