## Improvements

- **IoT Open decides who may do what.** App Management now reads the signed-in user's role in IoT Open and the installations assigned to the user, and follows IoT Open's permissions; there is nothing to configure on the server. Change the roles in IoT Open and App Management follows.
  - `gateway/reset/password`: set up, update, stop, start and remove the installation's edge client (by default *admin* on all installations, *owner* on assigned ones).
  - `edge/app/configured/list`: see the edge client's status and log (also *read_only*).
  - `edge/app/configured/create_delete` and `edge/app/configured/update`: install, remove and change apps.
- What the user may not do is not shown: buttons are hidden, the *Edge client* tab only appears for users who may see it, and a read-only user gets a note instead.
- `EDGE_ADMINS` is no longer required. It remains as an optional extra restriction on top of the IoT Open role.

## Upgrading

Download `deploy/compose.yml` again (it no longer requires `EDGE_ADMINS`) and set `APPMANAGEMENT_TAG=0.1.1` in `.env`, then `sudo docker compose pull && sudo docker compose up -d`.
