# App Management 0.1.11

## Fixed

- **A first release with unchanged code is no longer offered as an update.** An app installed from a commit (version `commit-20261027-2562ba3`) and then released without changing `app.lua` or `app.json`, for example when only a changelog was added, showed *Ny version 0.1.0*, but the update dialog went from the commit to the same commit: IoT Open recognises the code and keeps it under the commit's name. App Management now compares the release's `app.json` and `app.lua` with the installed commit's, and shows no update when they are the same.
- If the dialog is opened anyway and the code is the same, it says so and offers to save the settings instead of an update to the same version.

## Upgrade

`sudo appmanagement-update`, or by hand `APPMANAGEMENT_TAG=0.1.11` in `/opt/appmanagement/.env`, then `sudo docker compose pull && sudo docker compose up -d`.
