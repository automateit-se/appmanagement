# App Management 0.1.6

## Security

- The container now runs **Node.js 22.23.4**, which fixes the vulnerabilities in Node.js's security release of 21 October 2026, among them an out-of-bounds write in the Brotli decoder (CVE-2026-111497) and certificate hostname checks that could be bypassed (CVE-2026-106069). App Management's backend uses Node's `fetch` and TLS towards IoT Open and GitHub, so earlier images are affected.
- Node is pinned to the patch release in the `Dockerfile`, and the container build always fetches the base image again.

No functional changes.

## Upgrade

Set `APPMANAGEMENT_TAG=0.1.6` in `.env`, then `sudo docker compose pull && sudo docker compose up -d`. Check with `sudo docker compose exec appmanagement node --version` (v22.23.4).
