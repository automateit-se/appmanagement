# App Management 0.1.10

## Fixed

- **A new commit shows as *Ny version* for apps without releases.** Such an app gets its version from the latest commit on `main`, for example `commit-20261027-2562ba3`. Two commits from the same day were compared by their hash as text, so a new commit could look older than the installed one and no update was offered. Commits now compare by date, and on the same day the latest commit on GitHub is newer than any other installed commit. A release always replaces a commit.
- **README files and release notes are shown as on GitHub.** Tables are tables (with alignment), a wrapped line of a list item stays in its item, numbered lists are numbered, `*italic*` is italic, and relative links such as `[LICENSE](LICENSE)` show their text. Everything is still rendered without HTML, and only `https` links are links.

## New

- **`appmanagement-update`** updates the server with one command: the latest release, or a given version. It sets `APPMANAGEMENT_TAG`, fetches the matching `compose.yml`, pulls and restarts, and puts the previous version back if App Management does not answer within 60 s.

## Upgrade

Install the update command once, then run it:

```
sudo curl -fsSL -o /usr/local/bin/appmanagement-update \
  https://raw.githubusercontent.com/automateit-se/appmanagement/main/deploy/appmanagement-update
sudo chmod +x /usr/local/bin/appmanagement-update
sudo appmanagement-update
```

Or by hand: `APPMANAGEMENT_TAG=0.1.10` in `/opt/appmanagement/.env`, then `sudo docker compose pull && sudo docker compose up -d`.
