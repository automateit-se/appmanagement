# App Management 0.1.14

## New

- **Copy an installed app.** Each installed app has *Kopiera*. It opens the install dialog with the same version and settings filled in, so a new instance only needs what differs, for example another city, room, port or set of functions. The installed app is not changed. This makes it easy to run several instances of the same app side by side, each with its own settings.

## Changed

- **Free names for new instances.** When an app is installed, copied or installed next to an older version, the suggested name is one that no app on the installation has yet: *Väderdata*, then *Väderdata 2*, *Väderdata 3* and so on. Before, every instance was offered the app's own name.
- **The confirmation names the instance.** After an installation from *Lägg till app* it says, for example, *Väderdata 4 är installerad.*, with the name the instance got.

## Upgrade

`sudo appmanagement-update`, or by hand `APPMANAGEMENT_TAG=0.1.14` in `/opt/appmanagement/.env`, then `sudo docker compose pull && sudo docker compose up -d`.
