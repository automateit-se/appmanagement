# App Management 0.1.4

## Changes

- **App health.** For an installation whose edge client runs in App Management's Docker environment, every installed app shows whether it runs, how long it has run and how much memory it uses, or that it is crashing, with the number of crashes in the last hour and the latest error. The app's own log is one click away, and *Restart* restarts the app on the edge client. Read from the edge client's process list and log; nothing is run inside the container.
- The edge client page shows memory use against the container's limit and how many apps run.
- When the installation's edge client runs somewhere else (a gateway, a Raspberry Pi, another server), the edge client page says so, with its edge status in IoT Open, instead of saying that there is no edge client.

## Upgrade

Set `APPMANAGEMENT_TAG=0.1.4` in `.env`, then `sudo docker compose pull && sudo docker compose up -d`. `compose.yml` is unchanged since 0.1.3; the socket proxy already allows what is needed.
